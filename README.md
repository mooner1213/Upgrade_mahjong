# 업그레이드 마작 · Upgrade Mahjong

**기존 마작에 ‘세 가지 중 하나를 고르는 증강 카드’를 결합하는 1인 제작 게임입니다.**

강력한 증강 효과로 규칙과 승리 전략을 바꾸는 것이 핵심 기획입니다. 현재는 기본 마작과 대국 화면을 다듬는 프로토타입 단계이며 **증강 카드 선택·효과 시스템은 아직 미구현**입니다.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 제작 형태 | 1인 제작 |
| 현재 작업 | 기본 규칙·대국 흐름의 오류 수정과 디자인·UI 보완 |
| 핵심 기획 | 증강 카드 3개 중 1개를 선택해 색다른 전략으로 승리 |
| 현재 코드 | 리치 마작을 기반으로 한 로컬 4인 대국 프로토타입 |
| 추후 제작 | 최종 UI와 증강 선택·적용 시스템 |

본인은 증강 선택형 마작의 콘셉트를 구성하고 기본 게임의 잘못된 규칙과 화면·진행을 보완하며 제작하고 있습니다.

**[기획 방향과 후속 설계 항목](Docs/Planning/README.md)**

## 기획에서 의도한 경험

| 요소 | 설계 방향 |
| --- | --- |
| 기본 대국 | 패 구성과 타패·울기·화료 판단을 중심으로 마작의 기본 재미 구성 |
| 증강 선택 | 제시된 세 효과 중 하나를 선택해 이번 대국의 전략 결정 |
| 규칙 변화 | 강력한 카드 효과를 활용해 기존과 다른 승리 경로 탐색 |
| UI | 가능한 행동과 선택 결과 및 적용 효과를 이해할 수 있도록 정보 정리 |

증강의 제시 시점과 효과 지속 범위·중첩 및 구체적인 카드 목록은 후속 설계 대상입니다.

## 현재 저장소에서 확인할 수 있는 기능

아래는 코드에 포함된 기능이며 모든 마작 규칙의 정확성이 검증됐다는 의미는 아닙니다.

| 기능 | 포함된 처리 |
| --- | --- |
| 로컬 대국 | 사용자 1명과 컴퓨터 플레이어 3명의 패 분배·쯔모·타패·턴 진행 |
| 행동 선택 | 치·퐁·깡·리치·론·쯔모·패스와 복수 조합 선택 |
| 패 분석 | 화료 형태와 대기패 및 샨텐 계산 |
| 역과 점수 | 역 판정과 판·부·도라 및 론·쯔모 점수 계산 |
| 컴퓨터 플레이어 | 샨텐·유효패 수·도라 보존 등을 고려한 타패 판단 |
| 게임 화면 | 작탁·패 표현과 버림패·도라·플레이어 정보 및 행동·결과 UI |
| 화면 편집 | UI·작탁 배치 설정과 Editor 도구 |

현재 대국은 로컬 프로토타입입니다. 온라인 대전이나 증강 카드가 구현된 상태로 소개하지 않습니다.

## 실행 방법

1. Unity Hub에서 이 저장소 폴더를 프로젝트로 추가합니다.
2. **Unity 6000.3.13f1**로 엽니다.
3. 패키지 복원과 에셋 임포트가 끝나면 `Assets/Scenes/SampleScene.unity`를 엽니다.
4. Play Mode에서 대국 화면을 확인합니다.

패와 행동 선택은 화면 UI를 사용합니다. 복수의 치·깡 조합이 가능한 경우 선택 UI로 이어지도록 구성되어 있습니다.

## 검증과 구조 개선

이 문서는 코드와 씬 연결 및 개발자가 설명한 제작 범위를 기준으로 작성했습니다. 문서 작성 과정에서 Unity 실행·빌드 시험은 수행하지 않았습니다.

기본 게임을 다듬는 과정에서 다음 내용을 확인합니다.

- 화료와 역·점수 및 후리텐·울기 조건의 일관성
- 복수 행동과 조합 선택 및 대국 종료·다음 진행 연결
- 화면별 패 배치와 클릭 영역 및 말풍선 방향
- 큰 프로토타입 클래스에 모인 대국 진행·컴퓨터 판단·UI 생성 책임의 단계적 분리
- 복구 씬과 실제 플레이 씬의 역할 구분

현재 `UpgradeMahjongPrototype.cs`에는 여러 역할이 모여 있어 규칙 모듈이 나뉘어 있다는 사실만으로 구조 개선 완료를 판단하지 않습니다. `Assets/_Recovery`의 복구 씬은 플레이 시작 씬과 구분합니다.
