## 핵심 기획

세 가지 효과 중 하나를 선택해 기존과 다른 승리 전략을 만드는 경험을 목표로 합니다. 현재는 기본 규칙과 대국 화면을 다듬고 있으며 증강 카드 시스템은 후속 제작 대상입니다.

| 요소 | 설계 방향 |
| --- | --- |
| 기본 대국 | 패 구성과 타패·울기·화료 판단의 기반 제공 |
| 증강 선택 | 제시된 세 효과 중 이번 대국에 활용할 방향 선택 |
| 규칙 변화 | 카드 효과와 조합을 활용한 새로운 승리 경로 |
| UI | 가능한 행동과 선택 결과·적용 효과를 이해하기 쉽게 표시 |

## 현재 기능

| 기능 | 코드에 포함된 처리 |
| --- | --- |
| 대국 진행 | 패 분배·쯔모·타패·턴 진행 |
| 행동 선택 | 치·퐁·깡·리치·론·쯔모·패스와 복수 조합 선택 |
| 패 분석 | 화료 형태·대기패·샨텐 계산 |
| 역과 점수 | 역 판정과 판·부·도라 및 론·쯔모 점수 계산 |
| 컴퓨터 플레이어 | 샨텐·유효패 수·도라 보존 등을 고려한 타패 판단 |
| 화면 | 작탁·패·버림패·플레이어 정보와 행동·결과 UI 및 배치 편집 도구 |

기본 규칙과 판정은 계속 점검 중인 프로토타입입니다.

## 실행 방법

1. Unity Hub에서 프로젝트 폴더를 추가합니다.
2. **Unity 6000.3.13f1**로 열어 패키지 복원과 에셋 임포트를 기다립니다.
3. [SampleScene](Assets/Scenes/SampleScene.unity)을 엽니다.
4. Play Mode에서 패와 화면 UI를 선택하며 대국을 확인합니다.

복수의 치·깡 조합이 가능한 경우 조합 선택 UI로 이어집니다.
