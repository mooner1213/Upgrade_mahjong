# 업그레이드 마작 · 기획 방향

## 핵심 콘셉트

기존 마작 규칙에 강력한 효과의 증강 카드를 결합하는 1인 제작 프로젝트입니다. 제시된 카드 세 가지 중 하나를 골라 규칙과 승리 전략을 바꾸는 경험을 목표로 합니다.

## 기획 의도

| 기획 요소 | 목표 |
| --- | --- |
| 기본 마작 | 패 구성과 타패·울기 및 화료 판단의 기반 제공 |
| 3개 중 1개 선택 | 제시된 효과 중 이번 대국에 활용할 방향 선택 |
| 강력한 증강 효과 | 기본 규칙에서 벗어나는 조합과 색다른 승리 전략 제공 |
| 정보 표현 | 현재 적용 중인 효과와 행동 가능 조건을 이해할 수 있는 UI 구성 |

위 항목은 기획 목표입니다. 플레이 테스트로 확인된 효과나 완성된 증강 기능을 뜻하지 않습니다.

## 현재 제작 단계

현재는 기본 마작의 규칙과 대국 진행을 구현하고 잘못된 판정·디자인·UI를 보완하는 단계입니다. 기본 게임을 다듬은 뒤 최종 UI와 증강 선택·적용 시스템을 추가할 계획입니다.

| 구분 | 상태 |
| --- | --- |
| 기본 대국·룰·화면 코드 | 저장소에 포함. 오류 수정과 보완 진행 |
| 현행 UI와 디자인 | 프로토타입 화면을 개선 중 |
| 최종 UI | 추후 제작 |
| 증강 카드 3개 중 1개 선택 | 기획 단계 · 미구현 |
| 증강 효과 적용과 조합 | 기획 단계 · 미구현 |

## 후속 설계에서 정할 항목

다음은 증강 구현 전에 정할 상세 기준입니다. 현재 확정된 규칙이나 이미 구현한 기능으로 소개하지 않습니다.

- 증강을 제시하는 시점과 한 대국에서의 선택 횟수
- 효과가 유지되는 범위와 중첩 가능 여부
- 기본 마작의 역·화료·점수 계산과 효과가 충돌할 때의 처리 순서
- 카드 효과의 설명과 적용 중 상태를 보여 주는 UI
- 강력한 효과를 선택한 결과를 비교할 플레이 테스트 기준

증강의 구체적인 효과 목록과 수치 및 밸런스는 별도 설계·검증 대상으로 남깁니다.
